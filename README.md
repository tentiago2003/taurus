# Taurus

Plataforma de monitoramento e gerenciamento de dispositivos IoT.

## Primeiro MVP

O primeiro objetivo do Taurus é provar o fluxo básico:

MQTT → Backend → WebSocket → HTML

O sistema deverá:

- conectar a um broker MQTT;
- receber mensagens de dispositivos;
- interpretar os dados necessários;
- transmitir os dados via WebSocket;
- exibir os dados em uma página web em tempo real.

## Tecnologias iniciais

- Node.js
- MQTT
- WebSocket
- HTML
- JavaScript

## Princípios

O projeto será desenvolvido de forma incremental.

Cada etapa deverá:

1. ser pequena e objetiva;
2. ser implementada;
3. ser testada;
4. ser validada;
5. gerar um commit.

Não antecipar funcionalidades ou arquitetura que ainda não sejam necessárias.
